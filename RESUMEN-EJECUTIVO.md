BACKEND/API:
Astro API Routes + Supabase
├─ Razón: Escalable, real-time, row-level security
├─ PostgreSQL confiable, auth integrado
└─ Costo: $25/mes + gratis para MVP

DATABASE:
PostgreSQL (via Supabase)
├─ Tablas: paquetes, salidas, reservas, usuarios
├─ Real-time suscripciones
└─ Backups automáticos
